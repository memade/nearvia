# 直予 · Zhiyu

用于设备之间的消息与文件传输。原名 Nearvia。
Messaging and file transfer between devices. Formerly Nearvia.

目前候選版支援簡體中文、繁體中文與英文。

局域网传输消息与文件；蓝牙仅传短文字和回执。本版不提供跨网连接、中继和文件夹发送，也没有 Linux 或 Intel Mac 安装包。
區域網路傳輸訊息與檔案；藍牙僅傳短文字與回條。本版不提供跨網路連線、中繼及資料夾傳送，亦無 Linux 或 Intel Mac 安裝包。
Local-network messages and files; Bluetooth short text and receipts only. Cross-network connections, relays and folder sending are excluded. No Linux or Intel Mac installers.
