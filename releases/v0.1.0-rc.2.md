## 简体中文

直予（Zhiyu）0.1.0-rc.2，构建号 12，候选版。

- 界面名称由 Nearvia 更新为直予 / Zhiyu，应用标识和本地数据目录保持不变。
- 调整附近设备、沟通和设置页面，增加发送前的附件确认。
- 新增繁体中文；修复 Windows、macOS 窗口标题随语言切换。

下载：Android arm64 APK、macOS Apple Silicon DMG、Windows x64 ZIP。Mac 应用和 DMG 已正式签名、公证并附加票据。iOS 仅向登记设备定向提供。

支持局域网消息和文件；蓝牙仅传短文字与回执。跨网连接、中继和文件夹发送不在本版范围。更多机型、权限恢复和休眠恢复仍需验证。

升级前退出旧版，保留应用数据。安装步骤见 `INSTALL.md`，下载后核对 `SHA256SUMS`。

## English

Zhiyu 0.1.0-rc.2, build 12. Release candidate.

- Renamed the interface from Nearvia to Zhiyu. Application IDs and local data paths are unchanged.
- Updated Nearby, Chats and Settings; added attachment review before sending.
- Added Traditional Chinese and fixed language-dependent window titles on Windows and macOS.

Downloads: Android arm64 APK, Apple Silicon macOS DMG and Windows x64 ZIP. The Mac app and DMG are Developer ID signed, notarized and stapled. iOS is distributed privately to registered devices.

Local-network messages and files are supported. Bluetooth carries short text and receipts only. Cross-network connections, relays and folder sending are excluded. More devices, permission recovery and sleep recovery still need testing.

Quit the previous version and preserve app data before upgrading. See `INSTALL.md` and verify `SHA256SUMS`.
