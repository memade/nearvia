## 简体中文

免费的局域网消息与文件传输，以及蓝牙短文字和送达回执。首次连接须双方核对并确认安全码；蓝牙不传文件。跨互联网通信、中继、网络分享和发送文件夹不属于本轮交付。

- **Android arm64 / Android 7.0（API 24）及以上**：下载 APK，使用项目长期发行密钥签名。
- **macOS Apple Silicon / macOS 13 及以上**：打开 DMG，将 Nearvia.app 拖入“应用程序”。已使用 Developer ID 签名，完成 Apple 公证并附加票据。没有 Intel Mac 安装包。
- **iOS 15 及以上**：采用 Apple Distribution + Ad Hoc，需先联系开发者登记设备，再定向获取匹配的包。不是通用安装包，不在公开附件中提供 IPA，也未上架或通过 TestFlight 发行。请勿在公开 Issue 中提交设备标识。

本轮修复聊天输入区被表情/附件面板遮挡、iPhone 锁屏返回后的发现与连接恢复、已配对联系人显示，以及文件传输中断后的恢复。

**验证范围**：最终签名 build 10 在 Mac、Pixel 7 Pro、iPhone SE 覆盖升级后正常启动，旧联系人和聊天记录保留；Mac→Pixel→iPhone→Mac 消息及回执、Mac→Pixel 中文文件接收和打开通过。三端包内 SDK 与此前 7009 隔离验收包内容一致；隔离测试覆盖纯蓝牙六方向短文字、局域网大文件、指定锁屏时长与文件中断恢复。最终 Mac 包内 SDK 另通过拒绝/取消配对、双方确认、撤销信任后重启仍拒绝发送，以及错误密码、密码重封装和损坏数据拒绝检查。这些是不同层次的已测子集，**不代表全部 54 项或全部产品界面场景通过**。

**限制**：更多机型、权限拒绝后恢复、Mac 休眠、其他后台时长及长时间混合操作仍待验证。不承诺后台实时送达；未送达消息在发送端本机排队，恢复可用连接后继续尝试。首次打开可直接进入，可在设置中启用个人启动密码；未设置时没有个人密码保护。接收文件本体不属于数据库加密范围。重要资料请保留原件。

升级前退出旧版，**不要先卸载或清除数据**。Android 若提示签名不兼容请停止；旧研发签名包不能直接覆盖。Apple 平台当前 ID 是 `com.skstu.nearvia`，Android 保持 `com.skstu.sovkit`；不同 Apple ID 的更早安装不保证原位迁移。详细步骤见附件 `INSTALL.md`，下载后按 `SHA256SUMS` 核验。问题请附平台、系统版本、build 10 和复现步骤，勿上传密码、私钥、设备标识或未经脱敏的聊天记录。

## English

Free files and messages over a local network, plus Bluetooth short text and delivery receipts. Both devices must compare and confirm a security code. Bluetooth does not transfer files. Internet-wide connectivity, relay, network sharing and folder sending are outside this release.

- **Android arm64 / Android 7.0 (API 24)+**: install the APK, signed with the project's persistent release key.
- **Apple Silicon macOS / macOS 13+**: open the DMG and move Nearvia.app into Applications. Developer ID signed, Apple notarized and stapled. No Intel Mac installer.
- **iOS 15+**: private Apple Distribution / Ad Hoc packages for pre-registered devices. Contact the developer first; there is no universal public IPA, App Store or TestFlight release. Never post device identifiers in public issues.

Fixes include the composer being obscured by emoji/attachment panels, iPhone discovery and connection recovery after screen locking, paired-contact display and interrupted file transfer recovery.

**Tested scope:** final signed build 10 upgraded the Mac, Pixel 7 Pro and iPhone SE while retaining existing contacts and chat history. Messages and receipts passed Mac→Pixel→iPhone→Mac; a Chinese-named file was received and opened on Pixel from Mac. Embedded SDKs match the previously tested 7009 isolated hosts, whose tests covered six-direction Bluetooth short text, large LAN transfers, selected lock durations and file interruption recovery. The final Mac embedded SDK also passed pairing rejection/cancellation, mutual confirmation, revocation persisting across restart, wrong-password/corruption rejection and password rewrapping. These are bounded checks at different layers, **not a claim that all 54 cases or all product UI flows passed**.

**Limits:** more devices, permission recovery, Mac sleep, other background durations and prolonged mixed use remain untested. Always-on background delivery is not promised. Pending messages remain on the sender and retry when a usable connection returns. First launch needs no personal password; enable a startup password in Settings if desired. Without one, there is no personal-password protection. Received file contents are outside database encryption. Keep originals of important files.

Quit the old application before upgrading; **do not uninstall or clear data first**. Stop if Android reports an incompatible signature. Apple applications use `com.skstu.nearvia`; Android retains `com.skstu.sovkit`. In-place migration from earlier Apple applications with a different identifier is not promised. See `INSTALL.md` and verify `SHA256SUMS`. Report platform, OS, build 10 and reproduction steps without sensitive information.
